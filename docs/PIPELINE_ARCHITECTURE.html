Academic Landscape Analyzer

证据可追溯的学术文献群落分析管线 · 端到端流程架构

证据契约（Evidence Contract）

  • • 每条证据恰好绑定一个来源页
  • • 引文必须是原文连续逐字片段
  • • quote_exists 硬校验，未解析即 quote_not_found
  • • 全局证据 ID：paper_id::E1
  • • Stage 2 只见已验证证据，新引文即报错
  • • 时序由确定性代码生成，LLM 不得编造顺序

权威 vs 投影（Authority Boundary）

  • • 权威：原始 PDF · 解析页文本 · SQLite 快照 · EvidenceSpan
  • • 生产投影：Qdrant 向量 · Neo4j 图 · M5 检索 · 自建时序层
  • • 平行验证：getzep Graphiti / GTI（未接管主链）
  • • 投影全部可从权威重建，绝不反向覆盖
  • • 原始 PDF 永不直接进入 Graphiti
  • • Graphiti 仅 direct-bulk 写入，禁用 add_triplet 公共路径

技术栈与运行

  • • Python ≥3.12 · MIT · 无头 CLI
  • • LLM：OpenAI 兼容（默认 deepseek-v4-flash）
  • • Embedding：SiliconFlow bge-m3（1024d，批量 16）
  • • 可选：graphiti-core==0.30.2（GTI，唯一可选投影引擎）
  • • 本地 embedding：--embedding-backend local（显式选择）
  • • 83 测试文件 · pytest 9.1.1 · ruff 0.15.10
